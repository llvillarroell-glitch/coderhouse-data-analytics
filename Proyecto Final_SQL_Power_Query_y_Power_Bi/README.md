# Portafolio de Data Analytics · Lucas Villarroel Arancibia

Repositorio con los proyectos del programa de Data Analytics de Coderhouse: bases de datos y SQL, limpieza y transformación con Power Query (lenguaje M) y análisis en Power BI con DAX.

**Empieza por [`evaluacion-final-m11`](evaluacion-final-m11/)**: proyecto final con modelo relacional en SQL Server, consulta dinámica de los últimos 30 días, diagrama entidad-relación y una presentación ejecutiva para un equipo de marketing.

**Herramientas:** SQL Server (T-SQL, SSMS) · Power Query / lenguaje M · Power BI (DAX)

## Contenido

| Carpeta | Qué contiene |
